# Editor fonts

IBM Plex Mono, Regular and SemiBold, embedded in the editor. IBM Plex Sans,
which the editor's text is drawn in, is embedded in the engine's player
([its fonts](../../../engine/player/fonts/README.md)), since a game shows its
text in it too.
